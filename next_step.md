# Следующий шаг (Next Step)

**Задача:** Интеграция метрик для экспериментов Ablation Studies и Activation Patching.

**Описание:**
Логи тестирования многоагентного взаимодействия успешно проанализированы, ошибки памяти (OOM) учтены в инструкциях `AGENTS.md`. Фреймворк стабильно выполняет поставленные эксперименты. Теперь нужно расширить аналитические возможности агентов.

**План действий на следующий этап:**
1. Разработать и задокументировать стандартные метрики для экспериментов (например, Logit Difference, KL Divergence, Loss degradation).
2. Создать новый шаблон в `agent_workspace/templates/` для автоматического вычисления этих метрик после завершения экспериментов.
3. Обучить агента (обновить `AGENTS.md`) использовать эти метрики при оценке успешности подмены активаций или лоботомии (Ablation).
4. Проверить работоспособность метрик на тестовой задаче (например, Indirect Object Identification в GPT-2).
