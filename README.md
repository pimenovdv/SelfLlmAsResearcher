# Mechanistic Interpretability Agent Framework

Этот репозиторий содержит фреймворк для проведения экспериментов в области Mechanistic Interpretability нейросетей (таких как GPT-2, LLaMA) с помощью LLM-агентов.

## Архитектура
Платформа построена на базе паттерна ReAct (Reason + Act) и использует агентную архитектуру с двумя сущностями:
1. **LLM-Агент (Мозг):** Генерирует гипотезы и пишет код на основе поставленных целей.
2. **Target Model (Подопытный):** Языковая модель (например, GPT-2), на которой запускаются сгенерированные скрипты и проводятся эксперименты.

Обеспечена строгая изоляция среды выполнения для безопасности и стабильности работы.

## Ключевые возможности
* **Ablation Studies (Лоботомия):** Зануление attention heads или слоев для анализа влияния на поведение модели.
* **Анализ активаций (Activation Patching / Causal Intervention):** Подмена вектора контекста для проверки гипотез о хранении знаний.
* **Поиск уязвимостей:** Изучение джейлбрейков и обхода системных промптов на уровне весов.

## Структура проекта
* `src/` - Исходный код агентного цикла и инструментов.
* `agent_workspace/` - Директория-песочница для работы агента (сюда он пишет и запускает скрипты).
* `agent_workspace/templates/` - Шаблоны экспериментов (хуки, патчинг).
* `docs/` - Дополнительная документация.
* `AGENTS.md` - Инструкции для LLM-агентов.
* `TODO.md` - Список задач по развитию.

## Запуск
Среда должна запускаться в Docker-контейнере для изоляции и ограничения ресурсов.

### Конфигурация API ключей
Агент использует `openai` (или совместимый эндпоинт) в качестве LLM-драйвера. Вы можете настроить ключи несколькими способами:

1. **Использование `.env` файла (рекомендуется):**
   Создайте файл `.env` в корне проекта (или рядом со скриптом запуска):
   ```env
   OPENAI_API_KEY=ваш_секретный_ключ
   # OPENAI_BASE_URL=http://localhost:8000/v1  # Для локальных моделей (Ollama, vLLM)
   ```

2. **Передача через аргументы командной строки:**
   Вы можете передать ключ и URL напрямую при запуске:
   ```bash
   python src/agent_loop.py --api-key "ваш_секретный_ключ" --base-url "http://localhost:8000/v1" --model "llama3"
   ```

Для просмотра всех доступных аргументов запустите:
```bash
python src/agent_loop.py --help
```
