# End-to-End Circuit Diagram: Indirect Object Identification (IOI)

В данном документе представлена комплексная схема передачи информации (Information Flow) в задаче IOI на основе проведенных экспериментов с моделями `EleutherAI/gpt-neo-125m` и `JackFram/llama-160m`. Задача IOI заключается в том, чтобы модель предсказала косвенное дополнение (IO) после двух упоминаний субъекта (S1, S2). Пример промпта: "John and Mary went to the store, John gave a bottle to" -> " Mary".

Токены:
- **S1** (Subject 1) - Первое упоминание субъекта (например, John).
- **IO** (Indirect Object) - Косвенное дополнение (например, Mary).
- **S2** (Subject 2) - Второе упоминание субъекта (например, John).
- **END** - Последний токен перед предсказанием (например, to).

## Абстрактная схема потока данных (General Circuit Architecture)

```text
[Входные токены: S1, IO, S2, ..., END]
       |      |    |          |
       v      v    v          v
+---------------------------------------------------+
|               Ранние слои MLP (Layer 0)           |
|  - S2 MLP0: Извлекает и фиксирует факт            |
|    повторного появления субъекта                  |
+---------------------------------------------------+
                          | (Residual Stream)
                          v
+---------------------------------------------------+
|        S-Inhibition / Previous Token Heads        |
|  - Обрабатывают информацию о S2 и IO              |
|  - Передают сигнал ингибирования для Name Mover   |
|    Heads, блокируя повторную генерацию S2         |
+---------------------------------------------------+
                          | (Residual Stream)
                          v
+---------------------------------------------------+
|         Поздние слои MLP (на позиции END)         |
|  - Интегрируют информацию, полученную от          |
|    S-Inhibition Heads                             |
+---------------------------------------------------+
                          | (Residual Stream)
                          v
+---------------------------------------------------+
|                 Name Mover Heads                  |
|  - На позиции END собирают всю информацию и       |
|    повышают логиты для токена IO (Mary)           |
+---------------------------------------------------+
                          |
                          v
                  [Логиты ответа: IO]
```

## Детальный разбор по моделям

### 1. GPT-Neo 125m (`EleutherAI/gpt-neo-125m`)

У GPT-Neo основная вычислительная нагрузка по ингибированию ложится на самые ранние слои, с последующей интеграцией в поздних MLP слоях.

*   **S2 MLP (Layer 0):** Играет критическую роль в начальном извлечении признаков второго упоминания субъекта (падение Logit Diff до 2.05 при патчинге).
*   **S-Inhibition Heads:** Доминируют головы на **0-м слое** (L0H2, L0H6, L0H11), с дополнительным участием головы **L5H8**. Они формируют сигнал, подавляющий предсказание токена S2.
*   **END MLP (Layers 9, 10):** Полносвязные слои 9 и 10 на позиции токена END (последний токен промпта) отвечают за интеграцию этой информации непосредственно перед обращением к Name Mover Heads и финальной генерацией.

### 2. LLaMA-160m (`JackFram/llama-160m`)

У LLaMA-160m архитектура более глубокая и распределенная, и основная работа S-Inhibition сдвинута ближе к середине и концу сети.

*   **S2 MLP (Layer 0):** Абсолютно критичен для задачи. Патчинг этого слоя на позиции S2 полностью ломает способность модели выбрать правильный объект (Logit Diff падает до отрицательных значений: -0.80).
*   **S2 MLP (Layers 1-6):** Дополнительная, более распределенная обработка позиции второго субъекта через несколько ранних слоев.
*   **S-Inhibition Heads:** Ключевую роль играет более поздняя голова **L7H4** (падение на 1.74), а также головы средних слоев (**L3H2**, **L6H9**).
*   **END MLP (Layers 7-11):** Постепенная интеграция сигнала на позиции END. MLP слои с 7 по 11 шаг за шагом готовят итоговый вектор для генерации правильного ответа, снижая Logit Diff при их патчинге.

## Вывод
Несмотря на архитектурные различия (GPT-Neo выполняет S-Inhibition очень рано, LLaMA — в средних/поздних слоях), обе модели критически зависят от нулевого слоя MLP для инициализации признаков S2 и используют поздние MLP-слои на позиции END для финальной интеграции сигнала перед предсказанием.
