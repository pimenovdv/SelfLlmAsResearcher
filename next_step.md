# Следующий шаг (Next Step)

**Задача:** Гранулярный Activation Patching на уровне отдельных Attention Heads для Factual Recall.

**Описание:**
Мы завершили точечный патчинг MLP-слоев для задачи Factual Recall и определили, на каких позициях (Subject, END) происходит обработка фактов. Следующим логическим шагом является локализация конкретных голов внимания (Attention Heads), ответственных за извлечение фактологических знаний.

**План действий на следующий этап:**
1. Разработать скрипт для гранулярного патчинга Attention Heads в задаче Factual Recall.
2. Идентифицировать головы, передающие информацию от токена предмета (Subject) на последний токен (END).
3. Провести эксперименты (Ablation) для подтверждения их роли.
4. Документировать результаты (например, в `docs/factual_recall_circuit.md`).
