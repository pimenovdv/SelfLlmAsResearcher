# Следующий шаг (Next Step)

**Задача:** Использование Activation Patching для поиска слоев/голов, ответственных за In-Context Learning.

**Описание:**
Мы успешно реализовали базовый эксперимент (Baseline) для задачи In-Context Learning (предсказание следующего слова по аналогии: "apple -> red, banana -> yellow, grass -> green, sky -> blue") для `gpt2`.
Следующий логичный шаг — использование Activation Patching для поиска компонентов (в частности, Induction Heads), ответственных за перенос знаний из контекста.

**План действий на следующий этап:**
1. Подготовить коррумпированный промпт (например, заменив правильные цвета на случайные слова в примерах).
2. Написать скрипт Activation Patching для переноса активаций из чистого промпта в коррумпированный.
3. Оценить изменение Logit Difference (вероятность "blue" минус вероятность коррумпированного или случайного токена) при патчинге различных слоев.
4. Выявить слои, в которых происходит восстановление правильного предсказания.
