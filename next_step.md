# Следующий шаг (Next Step)

**Задача:** Написать тесты на переполнение контекста агента.

**Описание:**
Следующим шагом из `TODO.md` является написание тестов для проверки обработки переполнения контекста агента. В `ReActAgent` уже реализован механизм обрезки вывода (усечение вывода, если он больше 2000 символов). Необходимо покрыть этот функционал юнит-тестами, чтобы убедиться, что длинный консольный вывод (например, печать огромного тензора) правильно усекается и не вызывает сбоев из-за исчерпания контекстного окна LLM.

**План действий:**
1. Создать директорию `tests/`, если её нет.
2. Написать тест, который передает агенту скрипт, генерирующий очень длинный `stdout` (например, выводящий строку длиной 10000 символов).
3. Проверить, что метод `execute_script` (или сам цикл `run`) корректно обрезает этот вывод и добавляет сообщение "...[ВЫВОД ОБРЕЗАН ИЗ-ЗА ДЛИНЫ]...".
4. Убедиться, что `pytest` успешно проходит этот тест.
