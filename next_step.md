# Следующий шаг (Next Step)

**Задача:** Оптимизация и расширение ролей мультиагентной системы.

**Описание:**
Многоагентное взаимодействие (Researcher и Reviewer) было успешно реализовано. Следующим шагом стоит:
1. Создать роль агента-архитектора (Planner) для разбиения больших задач на подзадачи.
2. Провести тестирование на реальной задаче с использованием `llama3` или `gpt-4o` и оценить эффективность Reviewer'а (снизилось ли количество ошибок).
3. Добавить возможность Reviewer-агенту запускать дополнительные скрипты для верификации (в отдельной изолированной среде), прежде чем одобрять работу Researcher.

**План действий:**
1. Описать системные промпты для роли Planner.
2. Сделать пайплайн Planner -> (Researcher <-> Reviewer).
3. Интегрировать песочницу для Reviewer, чтобы он мог писать код проверки (Asserts).
