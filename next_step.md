# Следующий шаг (Next Step)

**Задача:** Обернуть инструменты агента в LangChain / AutoGen или самописный ReAct класс.

**Описание:**
В данный момент цикл работы агента (файл `src/agent_loop.py`) реализован как простой цикл `while`/`for`. Для создания более масштабируемого, гибкого и надежного решения нужно переписать логику работы агента (ReAct) с использованием классов, возможно с применением специализированного фреймворка (LangChain / AutoGen) или созданием надежной самописной обертки, которая будет инкапсулировать состояние агента, историю сообщений и обработку инструментов.

**План действий:**
1. Разработать архитектуру базового класса агента (`BaseAgent` или `ReActAgent`).
2. Интегрировать существующие функции (`execute_script`, `extract_code`) как инструменты класса агента.
3. Добавить управление историей диалога (сохранение контекста).
4. Заменить простой цикл в `agent_loop.py` на использование нового класса.
