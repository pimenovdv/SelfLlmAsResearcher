# Выявленные подсети (Circuits) и S-Inhibition Heads

В данном документе собраны результаты экспериментов по поиску специфичных голов внимания (Attention Heads), ответственных за передачу и ингибирование информации в различных задачах (в частности, IOI - Indirect Object Identification), для моделей GPT-Neo 125m и LLaMA-160m.

## Цель экспериментов
Анализ роли ранних и средних слоев (S-Inhibition Heads / Previous Token Heads) путем проведения точечного Activation Patching. При замене активаций этих голов с "чистого" промпта на "испорченный" (corrupted) наблюдается значительное падение метрики (Logit Difference), что указывает на их важную причинно-следственную роль в формировании правильного ответа.

## Результаты по моделям

### 1. GPT-Neo 125m (`EleutherAI/gpt-neo-125m`)
*   **Baseline Clean Logit Diff (Mary - John):** 4.2936
*   **Baseline Corrupted Logit Diff (Mary - John):** -4.2794

Выявленные потенциальные S-Inhibition/Previous Token Heads (на основе значительного падения Logit Diff при патчинге):
*   **Layer 0, Head 2:** Logit Diff падает до 2.5804 (падение = 1.7132)
*   **Layer 0, Head 5:** Logit Diff падает до 3.6298 (падение = 0.6637)
*   **Layer 0, Head 6:** Logit Diff падает до 3.0792 (падение = 1.2144)
*   **Layer 0, Head 7:** Logit Diff падает до 3.5190 (падение = 0.7746)
*   **Layer 0, Head 11:** Logit Diff падает до 2.9316 (падение = 1.3619)
*   **Layer 5, Head 8:** Logit Diff падает до 3.4479 (падение = 0.8457)

**Вывод:** У GPT-Neo 125m основная нагрузка по ингибированию/переносу предыдущего токена ложится на нулевой слой (головы 2, 6, 11), с дополнительным участием головы L5H8.

### 2. LLaMA-160m (`JackFram/llama-160m`)
*   **Baseline Clean Logit Diff (Mary - John):** 2.3162
*   **Baseline Corrupted Logit Diff (Mary - John):** -3.3666

Выявленные потенциальные S-Inhibition/Previous Token Heads:
*   **Layer 3, Head 2:** Logit Diff падает до 1.6674 (падение = 0.6488)
*   **Layer 6, Head 9:** Logit Diff падает до 1.7522 (падение = 0.5640)
*   **Layer 7, Head 4:** Logit Diff падает до 0.5763 (падение = 1.7399)

**Вывод:** У LLaMA-160m архитектура передачи информации отличается. Ключевую роль играет более поздняя голова **L7H4** (падение на 1.7399), а также средние слои (L3H2, L6H9). Ранние слои не показывают такой же выраженной роли, как у GPT-Neo.

## Дальнейшие шаги
Следующим шагом является точечный патчинг MLP (Многослойных персептронов) для анализа того, как информация из этих выявленных S-Inhibition голов обрабатывается и передается на финальные слои (Name Mover Heads), формирующие итоговое логит-распределение.
