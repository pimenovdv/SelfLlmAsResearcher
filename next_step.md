# Следующий шаг (Next Step)

**Задача:** Анализ и визуализация результатов Activation Patching для задачи Greater-Than

**Описание:**
Мы успешно провели расширенный эксперимент по Activation Patching на уровне отдельных attention heads для задачи Greater-Than (`experiments/greater_than_head_patching.py`). Результаты показали, что голова L07H10 при ее патчинге в одиночку восстанавливает около 36% разницы в вероятности правильного предсказания (года > заданного). Другие исследованные головы (L08H05, L08H10) не показали значимого индивидуального восстановления, а их совместный патчинг с L07H10 не улучшил результат.

Это свидетельствует о том, что L07H10 играет значимую причинно-следственную роль в передаче информации о пороге сравнения (Greater-Than), тогда как другие головы могут играть второстепенную или иную роль, которая проявляется при Ablation, но не при простом патчинге активаций.

**План действий на следующий этап:**
1. Разработать скрипты для более детального патчинга на уровне слоев или других компонентов, если нужно объяснить оставшуюся разницу (остальные 64%).
2. Возможно, разработать скрипт для визуализации активаций (например, attention patterns для головы L07H10) на ключах/запросах для года, чтобы лучше понять механизм.
3. Провести эксперимент по анализу S-Inhibition Heads и точечный патчинг MLP (следующие шаги из TODO для других задач).
