# LLaMA-160m Circuit Analysis for IOI Task

## 1. Overview
В данном документе описывается анализ подсети (circuit), ответственной за решение задачи Indirect Object Identification (IOI) в модели `JackFram/llama-160m`. Задача IOI заключается в том, чтобы модель, получив предложение вида "When John and Mary went to the store, John gave a drink to", правильно предсказала токен "Mary" вместо "John".

## 2. Name Mover Heads
Name Mover Heads — это головы внимания, которые переносят информацию об объекте (в данном случае "Mary") на последнюю позицию, повышая вероятность предсказания соответствующего токена.

В модели `llama-160m` (12 слоев) выявлены следующие потенциальные Name Mover Heads на поздних слоях (через Activation Patching):
- **Layer 9, Head 5**: Самое сильное падение Logit Difference (с 2.31 до -1.17, падение на 3.48) при подмене активаций corrupted инпутом.
- **Layer 10, Head 6**: Падение на 0.62.

Множественный Ablation этих двух голов (зануление их выходов) приводит к падению Baseline Clean Logit Diff с 2.3162 до 1.0568 (суммарное падение на 1.2594), что подтверждает их ключевую роль в формировании финального предсказания.

## 3. S-Inhibition Heads / Previous Token Heads
S-Inhibition Heads ингибируют (подавляют) внимание на Subject (в данном случае "John"), если он уже был упомянут второй раз (S2), что позволяет Name Mover Heads сфокусироваться на Indirect Object (IO).

На ранних слоях были найдены следующие потенциальные головы (по падению Logit Diff при патчинге):
- **Layer 3, Head 2** (Drop = 0.6488)
- **Layer 6, Head 9** (Drop = 0.5640)
- **Layer 7, Head 4** (Drop = 1.7399) - Самый сильный кандидат на S-Inhibition Head.

## 4. MLP Layers (Positional Patching)
Анализ полносвязных слоев (MLP) с точечным патчингом по позициям токенов показал, что:
- Наибольшее влияние на результат оказывает патчинг MLP на позиции **S2 ("John")** на **Layer 0** (Logit Diff падает до -0.8).
- Это говорит о том, что базовая обработка и привязка субъекта к контексту происходит в самом начале сети (на нулевом слое).
- На более поздних слоях (например, Layer 9 и Layer 10 на позиции END) MLP также начинает вносить вклад, что вероятно связано с формированием итогового эмбеддинга для предсказания следующего токена.

## Вывод
Архитектура решения задачи IOI в LLaMA-160m концептуально схожа с GPT-2 и GPT-Neo:
1. Ранние слои (MLP Layer 0) инициализируют позиционную/семантическую информацию.
2. Головы среднего уровня (Layer 7 Head 4) выполняют роль S-Inhibition, подавляя дублирующиеся имена.
3. Головы на поздних слоях (Layer 9 Head 5) переносят нужный токен (Name Mover Heads) для финального предсказания.
