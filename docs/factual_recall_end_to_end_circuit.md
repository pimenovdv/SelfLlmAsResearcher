# End-to-End Circuit Diagram: Factual Recall

В данном документе представлена обобщенная схема путей передачи информации для задачи Factual Recall на основе экспериментов с моделями `gpt2`, `EleutherAI/gpt-neo-125m` и `JackFram/llama-160m`.

Задача заключается в извлечении фактологической информации на основе контекста. Пример промпта: "The capital of France is" -> " Paris" (в противовес Corrupted: "The capital of Russia is" -> " Moscow").

## Абстрактная схема потока данных (General Circuit Architecture)

```text
[Входные токены: The, capital, of, France, is]
                     |                  |
                     v                  v
+---------------------------------------------------+
|               Ранние слои MLP (Layer 0)           |
|  - Формирование фундаментального представления    |
|    субъекта (Subject Processing)                  |
+---------------------------------------------------+
                     | (Residual Stream)
                     v
+---------------------------------------------------+
|          Factual Recall Attention Heads           |
|  - Извлекают фактологическую информацию из        |
|    Residual Stream и переносят её на финальный    |
|    токен (is) для предсказания                    |
+---------------------------------------------------+
                     |
                     v
           [Логиты ответа: Paris]
```

## Детальный разбор по моделям

### 1. GPT-2
У модели GPT-2 обработка фактов четко разделена на ранние слои (MLP) и поздние (Attention Heads).
*   **L0 MLP:** Критически важен для ранней обработки субъекта. Патчинг приводит к драматическому падению Logit Diff.
*   **Factual Recall Heads:** Доминируют головы на поздних слоях, особенно **L9H8**, а также **L10H0** и **L8H11**, которые непосредственно отвечают за перенос нужного факта на конечную позицию.

### 2. GPT-Neo 125m (`EleutherAI/gpt-neo-125m`)
Похожая архитектура, но Factual Recall головы смещены к самым последним слоям.
*   **L0 MLP:** Важнейший слой для 초기лизации представления субъекта, аналогично GPT-2.
*   **Factual Recall Heads:** Наибольший вклад вносят головы **L11H9** и **L9H5**, активно перемещающие информацию на финальный токен.

### 3. LLaMA-160m (`JackFram/llama-160m`)
Несмотря на архитектурные отличия, базовая концепция сохраняется.
*   **L0 MLP:** Абсолютно критичен. Патчинг L0 MLP обваливает Logit Diff сильнее всего (падение на ~15.6 пунктов).
*   **Factual Recall Heads:** В качестве ключевого узла переноса информации выступает голова **L10H6**.

## Вывод
Несмотря на различия в архитектурах моделей, задача Factual Recall устойчиво решается через единый шаблон: критическая зависимость от **Layer 0 MLP** для раннего связывания субъекта (Subject Processing) с последующим извлечением и передачей факта (Transmission) через выделенные **Factual Recall Heads** в поздних слоях сети.
