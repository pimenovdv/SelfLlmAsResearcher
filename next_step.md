# Следующий шаг (Next Step)

**Задача:** Локализация "Greater-Than Heads" с помощью точечного Ablation

**Описание:**
Мы успешно провели эксперимент с Activation Patching на уровне слоев (residual stream) для задачи Greater-Than (`experiments/greater_than_patching.py`). Результаты показали, что основная передача информации от начального года к конечному предсказанию (восстановление логитов для чисел больше 32) происходит на слоях с 5 по 9:
- Layer 5: ~20% восстановления
- Layer 6: ~35% восстановления
- Layer 7: ~68% восстановления
- Layer 8: ~83% восстановления
- Layer 9: ~99% восстановления

Следующий шаг — использовать точечный Ablation (отключение отдельных attention heads) на этих слоях, чтобы определить, какие именно головы внимания ("Greater-Than Heads") отвечают за логику сравнения и выбор чисел, больших заданного порога.

**План действий на следующий этап:**
1. Разработать скрипт `experiments/greater_than_ablation.py`.
2. В скрипте реализовать логику Ablation: отключать поочередно каждую голову внимания (занулять её выход) на слоях 5-11 и отслеживать падение вероятности для чисел > целевого года.
3. Построить тепловую карту или отсортированный список голов по их влиянию на задачу (насколько сильно падает probability(> year) при их отключении).
4. Задокументировать найденные "Greater-Than Heads" и обновить `TODO.md` и `next_step.md`.
