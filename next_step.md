# Следующий шаг (Next Step)

**Задача:** Реализовать песочницу для выполнения кода (`execute_python`) с жестким таймаутом и лимитом памяти.

**Описание:**
Для безопасного выполнения LLM-сгенерированного кода (особенно когда мы даем агентам писать и запускать код) необходимо улучшить существующий инструмент `execute_script`, который на текущий момент использует простой `subprocess.run` с таймаутом. Необходимо убедиться, что код исполняется в еще более изолированной среде (например, с лимитом памяти через `resource` на Linux) или, если он уже в Docker, настроить более жесткие политики, чтобы скрипты агента не могли исчерпать RAM / VRAM.

**План действий:**
1. Пересмотреть функцию `execute_script` в `ReActAgent` (файл `src/agent_loop.py`).
2. Добавить ограничения памяти для `subprocess`, например, с помощью модуля `resource` (в Linux) для ограничения максимального объема виртуальной памяти, доступной процессу, до разумных пределов.
3. Протестировать песочницу скриптом, который пытается съесть всю память.
4. Убедиться, что песочница корректно убивает процесс и возвращает читаемую ошибку агенту для Self-Correction.
