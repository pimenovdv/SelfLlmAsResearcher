# Архитектура эксперимента

## 1. Изолированная среда (Sandbox)
LLM-исследователь работает в Docker-контейнере, где предоставлены:
* **GPU доступ** для работы с моделями (`torch`).
* **Предустановленные библиотеки:** `PyTorch`, `Transformers`, `einops`, `transformer-lens`.
* **Доступ к файлам:** Директория `agent_workspace` изолирована и служит для запуска экспериментов и хранения артефактов (чекпоинты, json, графики в текстовом виде).

## 2. Разделение ролей
* **LLM-Агент (Мозг):** API модели (например, GPT-4o, Claude). Находится вне песочницы или взаимодействует через API. Отвечает за логику (ReAct), гипотезы и написание кода.
* **Target Model (Подопытный):** Модель, загруженная скриптом внутри песочницы (например, GPT-2). Веса этой модели препарируются и анализируются.

## 3. Базовые инструменты (Tools)
Агент снабжен инструментами для взаимодействия со средой:
* `execute_python(code)`: Запускает скрипты в песочнице и возвращает вывод. Встроен таймаут и усечение вывода для защиты от OOM и переполнения контекста.
* `read_file(path)`: Чтение файлов исходного кода или логов.
* `write_file(path, content)`: Запись Python-скриптов или промежуточных результатов.
* `bash_command(cmd)`: Управление окружением и установка зависимостей.

## 4. Цикл исследования
Фреймворк реализует цикл на основе ReAct:
1. **Осмотр:** Вывод архитектуры модели (с учетом агрегации).
2. **Гипотеза:** Формулирование гипотезы для проверки (напр. поиск нейронов со знаниями о столицах).
3. **Эксперимент:** Генерация Python-скрипта (например, с `register_forward_hook` или `run_with_cache`).
4. **Анализ:** Обработка результатов скрипта агентом и корректировка действий (включая самоисправление при получении Traceback).
